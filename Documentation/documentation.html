01 — Read first

What FreightFast is

A single Next.js application with a MySQL-compatible database. There's no separate backend service to stand up — the app, API routes, and background job endpoints all ship from the same codebase.

Three surfaces, one app

The build serves three distinct sign-in surfaces from the same deployment: an operations dashboard for company staff (quotations, shipments, finance), a platform console for the SaaS operator managing tenant companies, and a client portal your customers use to track their own shipments and documents. Routing between them is host-based, configured during installation.

Multi-tenant by design

Every record belongs to exactly one company, and within a company, to exactly one branch. If you're installing this for a single freight forwarder, you'll use one company with one or more branches; the platform console exists for cases where you're operating this as a SaaS across multiple client companies.

Role-based from the ground up

Seven predefined roles — Company Admin, Operations Manager, Documentation Officer, Accounts Officer, Sales Executive, and two more — gate every module, action, and record. Permissions are enforced server-side on every request, not just hidden in the UI.

02 — What's inside

Core features

Eighteen operational modules covering the full shipment lifecycle, from first inquiry to closed invoice.

Control Tower Dashboard

Real-time KPIs, shipment visibility, workflow blocker detection, revenue & profit analytics.

Customer & CRM Management

Customer database, company profiles, contacts, billing details, shipment history.

Shipment Request Management

Inquiry intake, cargo capture, Port-to-Port / Door-to-Door scope, auto-filled ETD/ETA.

Quotation Management

Freight & local charge estimation, buy/sell rates, profit visibility, approval workflow.

Job File Management

10-tab workspace: Overview, Workflow, Commercial, Operations, Documents, Freight Docs, Finance, Portal, Tasks, Timeline.

Document Compliance Engine

Mode/type-aware document requirements, required-document gates, finance close blockers.

Freight Document Generator

PDF generation for HBL, HAWB, sea/air manifests, delivery orders, debit notes, arrival notices.

Finance & Closeout

Invoicing, vendor bills, margin audit, financial lock, audit-safe closeouts.

Client Portal

OTP login, forced first-time password reset, milestone tracking, document access.

Role-Based Access Control

Seven predefined roles, fine-grained permissions, strict company isolation.

Multi-Branch Management

Every record owned by exactly one branch; staff scoped to the branches they belong to.

Automated Status Notifications

In-app alerts on invoice/payment/POD events, plus an idempotent email/WhatsApp outbox.

Advanced Global Search

One search box across customers, shipments, quotations, invoices, vendors, and documents.

Saved Filters & Views

Private, named filter presets on list pages, with a per-user default view.

Customizable Dashboard

Reorder and show/hide dashboard sections per user, with a one-click reset.

Import & Export Data

CSV export across eight entities; a guided import wizard for customers and vendors.

Recurring Task Management

Daily/weekly/monthly task templates, generated by an idempotent self-hosted cron.

Custom Document Templates

Branded, versioned layouts for quotations, invoices, HBL, HAWB, debit notes, manifests.

Approval Workflow System

Threshold-based sign-off chains for vendor bills and payments, up to five approver steps.
