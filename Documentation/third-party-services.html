Third-party services

FreightFast can integrate with a handful of external services. Exactly one is required to run the app at all — the rest are optional, and each feature that needs one simply stays switched off until it's configured.

Everything below the database is opt-in. Install the app, run it, and add these later as you need them — nothing has to be decided on day one.

02 — Required

Database

The only hard external dependency. Every record — shipments, quotations, invoices, users — lives here.

Self-hosted: install MySQL 8.0 or MariaDB 10.6+ on the same server as the app. No ongoing cost beyond the server itself.

Managed: a hosted MySQL-compatible database (e.g. Amazon RDS, DigitalOcean Managed Databases, PlanetScale) removes the need to administer the database server yourself, at the cost of the provider's hosting fee. Either path works — set DATABASE_URL to point at whichever you choose.

03 — Optional

File storage — Azure Blob Storage

Powers the Shipment Document Vault — uploaded freight documents, HBL/HAWB copies, and other shipment files.

Without AZURE_STORAGE_CONNECTION_STRING configured, document upload is unavailable but the rest of the app functions normally. Azure's free-tier credits for new accounts are typically enough to evaluate the feature before committing to a paid plan.

04 — Optional

AI features — Google Gemini

Ten of the fifteen AI-assisted tools (Document Reader, Document Checker, Quotation Generator, Email Generator, and others) call the Gemini API. The remaining five are deterministic and need no external service.

Get a key from Google AI Studio and set GOOGLE_GENERATIVE_AI_API_KEY, plus AI_ENABLED=true. Gemini's free tier covers moderate usage; heavier volume moves to its paid pricing. Without a key configured, every AI feature — including the five deterministic ones, which share the same permission gate — stays switched off.

05 — Optional

Delivery channels

In-app notifications always work with no setup. These three only govern sending a copy externally.

Email — any SMTP provider

Point SMTP_HOST/SMTP_PORT/SMTP_USER/SMTP_PASS at any SMTP relay — a transactional email provider, your own mail server, or even a personal account for testing. Pricing and free-tier limits vary by provider.

WhatsApp — Meta WhatsApp Cloud API

Requires a Meta for Developers app with the WhatsApp Business Platform enabled. Meta bills per conversation once you're past its free tier — see Meta's own pricing for current rates.

SMS — any SMS gateway

Plug in whichever regional SMS API provider you prefer via SMS_PROVIDER/SMS_API_KEY. Cost is per-message and varies significantly by provider and destination country.
