# Known Limitations And Roadmap

This demo focuses on the core operating workflow for a freight forwarding company. The items below are not weaknesses of the demo; they are planned extension areas once the pilot confirms the exact business process.

## Real-Time Shipping Line / Airline / API Integration

Current demo status: manual or system-tracked shipment updates.

Roadmap direction: connect selected carriers, airlines, ports, customs, or tracking providers where reliable APIs are available and commercially useful.

## Deep Accounting

Current demo status: freight file invoices, vendor bills, payments, receivable/payable, finance closeout, and final profit snapshot.

Roadmap direction: integration with accounting software or deeper ledger functions after finance workflow is confirmed.

## Tax / VAT

Current demo status: demo finance examples are simplified.

Roadmap direction: add Bangladesh-specific tax/VAT rules and invoice requirements based on client policy and accountant review.

## Claim / Dispute Management

Current demo status: not included as a dedicated module.

Roadmap direction: add claim/dispute tracking for damaged cargo, late delivery, short delivery, billing dispute, and document dispute workflows.

## Customs / Shipping-Line External Integration

Current demo status: customs and shipping-line records can be tracked as operational data, but external systems are not integrated.

Roadmap direction: integrate high-value external systems only after confirming data availability, reliability, and cost.

## Advanced Excel / PDF Export

Current demo status: reports and pages are available in-app, with selected print/PDF surfaces already present in the product.

Roadmap direction: add advanced Excel, PDF, and management report export packs after the report formats are finalized with pilot users.

## Production Deployment Hardening

Current demo status: local demo environment.

Roadmap direction: production hosting, backups, monitoring, domain/SSL, data migration, user onboarding, audit policy, and support workflow.
